--- layout: page --- {%- comment -%} Lab page layout. Any directory under labs/ that contains an index.md becomes a lab page. This layout finds the files sitting in that same directory and lays them out: the PDF handout (linked and embedded), then every .py source file shown inline with a download link, then anything else as a plain link. Nothing here is hard-coded to a particular lab. To add Lab 2: create labs/Lab2/, drop the PDF and the .py files in, and add an index.md with a title and an order. _config.yml applies this layout automatically. Caveat: files pulled in with include_relative are run through Liquid, so a source file containing Liquid delimiters would need a raw block around it.
